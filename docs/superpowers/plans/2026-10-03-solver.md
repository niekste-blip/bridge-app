# Solver: slagen uitrekenen met open kaarten — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** De module `solver` bouwen: voor een stand in het afspel met vier open handen uitrekenen hoeveel slagen elke speelbare kaart oplevert als daarna iedereen foutloos speelt.

**Architecture:** De zoekfunctie werkt op een eigen compacte voorstelling: per speler en per kleur een bitmasker van 13 bits. Ze beantwoordt steeds de vraag "kan Noord-Zuid minstens N slagen halen?" en vindt het exacte aantal door die vraag met verschillende N te stellen. Een tabel onthoudt standen aan het begin van een slag, opgeslagen naar onderlinge rangorde van de kaarten, zodat gelijkwaardige standen één keer worden uitgerekend. `solve` vertaalt een `PlayState` uit `core` naar die voorstelling en terug.

**Tech Stack:** TypeScript (strict), Vitest. Bouwt op `src/core`.

Spec: `docs/superpowers/specs/2026-10-03-bridge-app-design.md`, stap 3 van de bouwvolgorde.

### Task 1: De zoekfunctie

**Files:**
- Create: `src/solver/search.ts`
- Test: `src/solver/search.test.ts`

**Interfaces:**
- Consumes: niets
- Produces:
  - `NO_TRUMP = 4`
  - `class Search`
    - `constructor(trump: number)` (0-3 voor een troefkleur, `NO_TRUMP` voor SA)
    - `readonly hands: Int32Array` (16 maskers; index `plaats * 4 + kleur`, bit `rang`)
    - `readonly trickSuit: Int8Array`, `readonly trickRank: Int8Array` (kaarten van de lopende slag vanaf index 0; de zoekfunctie gebruikt de volgende posities voor latere slagen)
    - `nsTricks(leader: number, played: number, left: number): number` — het exacte aantal slagen voor Noord-Zuid uit de `left` slagen die nog niet af zijn. `leader` kwam uit in de lopende slag, waarin al `played` kaarten liggen (in `trickSuit`/`trickRank` op 0 tot en met `played - 1`).
    - `canTake(leader: number, played: number, need: number, left: number, base: number): boolean` — kan Noord-Zuid minstens `need` van die slagen halen? `base` is de positie van de eerste kaart van de lopende slag in `trickSuit`/`trickRank`; van buitenaf altijd 0.
    - `winnerIndex(base: number): number` — de positie (0-3) binnen de slag van de winnende kaart

Hoe de zoekfunctie werkt:

- **Nulvenster:** `canTake` geeft alleen ja of nee. De speler aan de beurt van Noord-Zuid zoekt één kaart die "ja" oplevert; een speler van Oost-West zoekt één kaart die "nee" oplevert.
- **Tabel:** aan het begin van een slag wordt de stand opgezocht. De sleutel bevat per kleur wie welke van de overgebleven kaarten heeft, genummerd van laag naar hoog. Een stand met A-V tegen H-B is daardoor dezelfde als H-10 tegen V-9 wanneer de tussenliggende kaarten al gespeeld zijn. De tabel bewaart een onder- en bovengrens voor het aantal slagen en wordt geleegd bij twee miljoen standen.
- **Aaneengesloten kaarten:** van kaarten die elkaar opvolgen (ook als de kaarten ertussen al gespeeld zijn) wordt er één geprobeerd.
- **Zekere slagen:** heeft de uitkomende speler kaarten die hoger zijn dan alle andere kaarten in die kleur, dan telt dat als ondergrens. In een troefcontract tellen de bijkleuren alleen als de tegenstanders geen troef meer hebben.
- **Volgorde van proberen:** uitkomen met kaarten die niemand kan slaan; anders de goedkoopste kaart die de slag wint; anders de laagste.

```ts
import { describe, expect, it } from 'vitest';
import { NO_TRUMP, Search } from './search';

const SEAT = { N: 0, E: 1, S: 2, W: 3 } as const;
const SUIT = { C: 0, D: 1, H: 2, S: 3 } as const;
const RANKS = '23456789TJQKA';

// Puts cards such as 'SA' or 'H2' in the hand of a seat
function give(search: Search, seat: keyof typeof SEAT, ...cards: string[]): void {
  for (const card of cards) {
    const suit = SUIT[card[0] as keyof typeof SUIT];
    search.hands[SEAT[seat] * 4 + suit] |= 1 << RANKS.indexOf(card[1]);
  }
}

function twoCardEnding(trump: number): Search {
  const search = new Search(trump);
  give(search, 'N', 'SA', 'SK');
  give(search, 'E', 'S2', 'S3');
  give(search, 'S', 'H2', 'H3');
  give(search, 'W', 'S4', 'C2');
  return search;
}

describe('Search', () => {
  it('counts the tricks for North-South with North on lead', () => {
    expect(twoCardEnding(NO_TRUMP).nsTricks(SEAT.N, 0, 2)).toBe(2);
  });

  it('lets a defender ruff', () => {
    expect(twoCardEnding(SUIT.C).nsTricks(SEAT.N, 0, 2)).toBe(1);
  });

  it('depends on who leads', () => {
    // West leads the club: it wins in no trump, and then the spade is lost to North
    expect(twoCardEnding(NO_TRUMP).nsTricks(SEAT.W, 0, 2)).toBe(1);
  });

  it('leaves the hands as they were', () => {
    const search = twoCardEnding(NO_TRUMP);
    const before = [...search.hands];
    search.nsTricks(SEAT.N, 0, 2);
    expect([...search.hands]).toEqual(before);
  });

  it('answers whether a number of tricks can be made', () => {
    const search = twoCardEnding(NO_TRUMP);
    expect(search.canTake(SEAT.N, 0, 2, 2, 0)).toBe(true);
    expect(search.canTake(SEAT.N, 0, 3, 2, 0)).toBe(false);
    expect(search.canTake(SEAT.N, 0, 0, 2, 0)).toBe(true);
  });

  it('finds the winner of a trick', () => {
    const search = new Search(SUIT.H);
    const trick: [number, number][] = [
      [SUIT.S, 5],
      [SUIT.S, 12],
      [SUIT.H, 0],
      [SUIT.D, 12],
    ];
    trick.forEach(([suit, rank], index) => {
      search.trickSuit[index] = suit;
      search.trickRank[index] = rank;
    });
    expect(search.winnerIndex(0)).toBe(2); // the small trump beats the ace of spades
    expect(new Search(NO_TRUMP).winnerIndex(0)).toBe(0); // an empty trick: the first card stands
  });
});
```

`src/solver/search.ts`:

```ts
// Double dummy search on a compact position: one 13-bit mask per seat and suit.
// Seats are 0..3 (N, E, S, W), suits 0..3 (C, D, H, S), trump 4 means no trump.
// All values count tricks for North-South.

export const NO_TRUMP = 4;
const MAX_ENTRIES = 2_000_000;

export class Search {
  readonly hands = new Int32Array(16);
  readonly trickSuit = new Int8Array(52);
  readonly trickRank = new Int8Array(52);
  private readonly table = new Map<string, number>();
  private readonly moveSuit = new Int8Array(52 * 13);
  private readonly moveRank = new Int8Array(52 * 13);
  private readonly moveScore = new Int16Array(52 * 13);

  constructor(readonly trump: number) {}

  // Exact number of tricks North-South take from here with best play by both sides
  nsTricks(leader: number, played: number, left: number): number {
    let low = 0;
    let high = left;
    while (low < high) {
      const middle = (low + high + 1) >> 1;
      if (this.canTake(leader, played, middle, left, 0)) low = middle;
      else high = middle - 1;
    }
    return low;
  }

  // Can North-South take at least `need` of the `left` tricks that are not finished yet?
  canTake(leader: number, played: number, need: number, left: number, base: number): boolean {
    if (need <= 0) return true;
    if (need > left) return false;

    let key = '';
    let bounds = left << 4;
    if (played === 0) {
      key = this.key(leader);
      const stored = this.table.get(key);
      if (stored !== undefined) {
        bounds = stored;
        if ((bounds & 15) >= need) return true;
        if (bounds >> 4 < need) return false;
      }
    }

    const seat = (leader + played) & 3;
    const northSouth = (seat & 1) === 0;
    if (played === 0) {
      const sure = this.sureTricks(leader);
      if (northSouth ? sure >= need : sure > left - need) {
        return northSouth;
      }
    }
    const first = (base + played) * 13;
    const count = this.generate(seat, played, base, first);
    let result = !northSouth;
    for (let i = 0; i < count; i++) {
      // Selection sort step: best remaining move first
      let best = i;
      for (let j = i + 1; j < count; j++) {
        if (this.moveScore[first + j] > this.moveScore[first + best]) best = j;
      }
      const suit = this.moveSuit[first + best];
      const rank = this.moveRank[first + best];
      this.moveSuit[first + best] = this.moveSuit[first + i];
      this.moveRank[first + best] = this.moveRank[first + i];
      this.moveScore[first + best] = this.moveScore[first + i];

      const bit = 1 << rank;
      this.hands[seat * 4 + suit] ^= bit;
      this.trickSuit[base + played] = suit;
      this.trickRank[base + played] = rank;
      let outcome: boolean;
      if (played === 3) {
        const winner = (leader + this.winnerIndex(base)) & 3;
        const won = (winner & 1) === 0 ? 1 : 0;
        outcome = this.canTake(winner, 0, need - won, left - 1, base + 4);
      } else {
        outcome = this.canTake(leader, played + 1, need, left, base);
      }
      this.hands[seat * 4 + suit] ^= bit;
      if (outcome === northSouth) {
        result = northSouth;
        break;
      }
    }

    if (played === 0) {
      if (this.table.size >= MAX_ENTRIES) this.table.clear();
      const low = bounds & 15;
      const high = bounds >> 4;
      this.table.set(key, result ? Math.max(low, need) | (high << 4) : low | (Math.min(high, need - 1) << 4));
    }
    return result;
  }

  // Tricks the leader can cash at once: cards that beat every other card of their suit.
  // In a trump contract side suits only count when the opponents have no trumps left.
  private sureTricks(leader: number): number {
    const hands = this.hands;
    const left = (leader + 1) & 3;
    const right = (leader + 3) & 3;
    const partner = (leader + 2) & 3;
    const trump = this.trump;
    const ruffRisk =
      trump !== NO_TRUMP && (hands[left * 4 + trump] | hands[right * 4 + trump]) !== 0;
    let sure = 0;
    for (let suit = 0; suit < 4; suit++) {
      if (ruffRisk && suit !== trump) continue;
      const mine = hands[leader * 4 + suit];
      if (mine === 0) continue;
      const others = hands[left * 4 + suit] | hands[right * 4 + suit] | hands[partner * 4 + suit];
      for (let rank = 12; rank >= 0; rank--) {
        const bit = 1 << rank;
        if (mine & bit) sure++;
        else if (others & bit) break;
      }
    }
    return sure;
  }

  // Index (0..3) within the trick starting at `base` of the card that wins it
  winnerIndex(base: number): number {
    let best = 0;
    for (let i = 1; i < 4; i++) {
      const suit = this.trickSuit[base + i];
      const bestSuit = this.trickSuit[base + best];
      if (suit === bestSuit) {
        if (this.trickRank[base + i] > this.trickRank[base + best]) best = i;
      } else if (suit === this.trump) {
        best = i;
      }
    }
    return best;
  }

  // Writes the moves of `seat` at `first`; one card per group of touching cards
  private generate(seat: number, played: number, base: number, first: number): number {
    let count = 0;
    const ledSuit = played > 0 ? this.trickSuit[base] : -1;
    const follows = ledSuit >= 0 && this.hands[seat * 4 + ledSuit] !== 0;

    // The card that is winning the trick so far
    let winning = -1;
    let winningSuit = -1;
    let winningRank = -1;
    for (let i = 0; i < played; i++) {
      const suit = this.trickSuit[base + i];
      const rank = this.trickRank[base + i];
      if (winning < 0 || (suit === winningSuit ? rank > winningRank : suit === this.trump)) {
        winning = i;
        winningSuit = suit;
        winningRank = rank;
      }
    }
    const partnerWinning = played >= 2 && winning === played - 2;

    for (let suit = 0; suit < 4; suit++) {
      if (follows && suit !== ledSuit) continue;
      const mine = this.hands[seat * 4 + suit];
      if (mine === 0) continue;
      let others = 0;
      for (let other = 0; other < 4; other++) {
        if (other !== seat) others |= this.hands[other * 4 + suit];
      }
      for (let i = 0; i < played; i++) {
        if (this.trickSuit[base + i] === suit) others |= 1 << this.trickRank[base + i];
      }
      let inRun = false;
      for (let rank = 12; rank >= 0; rank--) {
        const bit = 1 << rank;
        if ((mine & bit) === 0) {
          if (others & bit) inRun = false;
          continue;
        }
        if (inRun) continue;
        inRun = true;

        let score: number;
        if (played === 0) {
          // Lead: cards nobody can beat first, then low cards
          score = bit > others ? 40 + rank : 12 - rank;
          if (suit === this.trump) score += 1;
        } else {
          const beats =
            suit === winningSuit ? rank > winningRank : suit === this.trump;
          if (partnerWinning) score = 30 - rank - (beats ? 20 : 0);
          else if (beats) score = 60 - rank;
          else score = 30 - rank - (suit === this.trump ? 20 : 0);
        }
        this.moveSuit[first + count] = suit;
        this.moveRank[first + count] = rank;
        this.moveScore[first + count] = score;
        count++;
      }
    }
    return count;
  }

  // Positions with the same relative ranks share one entry
  private key(leader: number): string {
    const hands = this.hands;
    let key = String(leader);
    for (let suit = 0; suit < 4; suit++) {
      const north = hands[suit];
      const east = hands[4 + suit];
      const south = hands[8 + suit];
      let all = north | east | south | hands[12 + suit];
      let a = 0;
      let b = 0;
      let out = 1;
      while (all) {
        const bit = all & -all;
        all ^= bit;
        if (north & bit) a |= out;
        else if (east & bit) a |= out << 13;
        else if (south & bit) b |= out;
        else b |= out << 13;
        out <<= 1;
      }
      key += ',' + a + ',' + b;
    }
    return key;
  }
}
```

```ts
import { describe, expect, it } from 'vitest';
import {
  type Card,
  type Contract,
  type Deal,
  type PlayState,
  type Strain,
  cardId,
  fullDeck,
  isPlayComplete,
  legalCards,
  parseCard,
  playCard,
  seatToPlay,
  seededRng,
  sideOf,
  startPlay,
} from '../core';
import { bestTricks, solve } from './index';

// A random ending with `size` cards in each hand
function ending(seed: number, size: number): Deal {
  const rng = seededRng(seed);
  const deck = fullDeck();
  for (let i = deck.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [deck[i], deck[j]] = [deck[j], deck[i]];
  }
  return {
    N: deck.slice(0, size),
    E: deck.slice(size, 2 * size),
    S: deck.slice(2 * size, 3 * size),
    W: deck.slice(3 * size, 4 * size),
  };
}

function contract(strain: Strain, declarer: Contract['declarer']): Contract {
  return { level: 1, strain, doubling: 'none', declarer };
}

// Plain minimax through the core play functions: tricks for North-South from here
function bruteForce(state: PlayState): number {
  if (isPlayComplete(state)) return 0;
  const northSouth = sideOf(seatToPlay(state)) === 'NS';
  let best = northSouth ? -1 : 99;
  for (const card of legalCards(state)) {
    const next = playCard(state, card);
    const finished = next.completed.length > state.completed.length;
    const won = finished && sideOf(next.completed[next.completed.length - 1].winner) === 'NS' ? 1 : 0;
    const value = won + bruteForce(next);
    best = northSouth ? Math.max(best, value) : Math.min(best, value);
  }
  return best;
}

// The same number from the point of view of the player to move, for one card
function expected(state: PlayState, card: Card): number {
  const next = playCard(state, card);
  const finished = next.completed.length > state.completed.length;
  const won = finished && sideOf(next.completed[next.completed.length - 1].winner) === 'NS' ? 1 : 0;
  const northSouthTricks = won + bruteForce(next);
  const left = state.hands[seatToPlay(state)].length;
  return sideOf(seatToPlay(state)) === 'NS' ? northSouthTricks : left - northSouthTricks;
}

const cards = (...ids: string[]) => ids.map(parseCard);

describe('solve', () => {
  it('counts top tricks in no trump', () => {
    const deal: Deal = {
      N: cards('SA', 'SK', 'H2'),
      E: cards('SQ', 'SJ', 'HA'),
      S: cards('S2', 'S3', 'H3'),
      W: cards('S4', 'S5', 'HK'),
    };
    // West is declarer, so North leads: two spades, then the hearts are lost
    const results = solve(startPlay(deal, contract('NT', 'W')));
    const byCard = Object.fromEntries(results.map((r) => [cardId(r.card), r.tricks]));
    expect(byCard).toEqual({ SA: 2, SK: 2, H2: 2 });
  });

  it('sees a ruff', () => {
    const deal: Deal = {
      N: cards('SA', 'SK'),
      E: cards('S2', 'S3'),
      S: cards('H2', 'H3'),
      W: cards('S4', 'C2'),
    };
    // West is declarer, North leads. With clubs as trumps West ruffs the second spade.
    expect(bestTricks(startPlay(deal, contract('NT', 'W')))).toBe(2);
    expect(bestTricks(startPlay(deal, contract('C', 'W')))).toBe(1);
  });

  it('gives a result for every legal card', () => {
    const state = startPlay(ending(1, 5), contract('H', 'N'));
    expect(solve(state).map((r) => cardId(r.card))).toEqual(legalCards(state).map(cardId));
  });

  it('does not change the state', () => {
    const state = startPlay(ending(2, 5), contract('S', 'E'));
    const before = JSON.stringify(state);
    solve(state);
    expect(JSON.stringify(state)).toBe(before);
  });

  it('matches plain minimax on random four-card endings', () => {
    const strains: Strain[] = ['NT', 'S', 'H', 'D', 'C'];
    for (let seed = 1; seed <= 40; seed++) {
      const strain = strains[seed % strains.length];
      const declarer = (['N', 'E', 'S', 'W'] as const)[seed % 4];
      const state = startPlay(ending(seed, 4), contract(strain, declarer));
      for (const result of solve(state)) {
        expect(result.tricks, `seed ${seed} ${cardId(result.card)}`).toBe(expected(state, result.card));
      }
    }
  });

  it('matches plain minimax in the middle of a trick', () => {
    for (let seed = 41; seed <= 70; seed++) {
      let state = startPlay(ending(seed, 4), contract(seed % 2 ? 'NT' : 'C', 'S'));
      const cardsPlayed = 1 + (seed % 6); // stops inside the first or the second trick
      for (let i = 0; i < cardsPlayed; i++) {
        const options = legalCards(state);
        state = playCard(state, options[seed % options.length]);
      }
      for (const result of solve(state)) {
        expect(result.tricks, `seed ${seed} ${cardId(result.card)}`).toBe(expected(state, result.card));
      }
    }
  });

  it('solves eight-card endings quickly', () => {
    const start = performance.now();
    for (let seed = 1; seed <= 10; seed++) {
      solve(startPlay(ending(seed, 8), contract(seed % 2 ? 'NT' : 'S', 'S')));
    }
    expect(performance.now() - start).toBeLessThan(5000);
  });
});
```

```ts
import { type Card, type PlayState, SEATS, SUITS, legalCards, seatToPlay } from '../core';
import { NO_TRUMP, Search } from './search';

export interface CardResult {
  readonly card: Card;
  // Tricks the side of the player to move takes from the unfinished tricks
  // when this card is played and both sides play perfectly with open cards
  readonly tricks: number;
}

// One search per trump: its table holds positions by relative rank, so it stays valid across deals
const searches = new Map<number, Search>();

function searchFor(trump: number): Search {
  let search = searches.get(trump);
  if (!search) {
    search = new Search(trump);
    searches.set(trump, search);
  }
  return search;
}

export function solve(state: PlayState): CardResult[] {
  const trump = state.trump === 'NT' ? NO_TRUMP : SUITS.indexOf(state.trump);
  const search = searchFor(trump);
  search.hands.fill(0);
  SEATS.forEach((seat, seatIndex) => {
    for (const card of state.hands[seat]) {
      search.hands[seatIndex * 4 + SUITS.indexOf(card.suit)] |= 1 << (card.rank - 2);
    }
  });

  const leader = SEATS.indexOf(state.current.leader);
  const played = state.current.cards.length;

  const mover = seatToPlay(state);
  const moverIndex = SEATS.indexOf(mover);
  const northSouth = (moverIndex & 1) === 0;
  const left = state.hands[mover].length;

  return legalCards(state).map((card) => {
    const suit = SUITS.indexOf(card.suit);
    const bit = 1 << (card.rank - 2);
    search.hands[moverIndex * 4 + suit] ^= bit;
    // The search reuses these slots for later tricks, so the current trick is written for every card
    state.current.cards.forEach((earlier, index) => {
      search.trickSuit[index] = SUITS.indexOf(earlier.suit);
      search.trickRank[index] = earlier.rank - 2;
    });
    search.trickSuit[played] = suit;
    search.trickRank[played] = card.rank - 2;
    let tricks: number;
    if (played === 3) {
      const winner = (leader + search.winnerIndex(0)) & 3;
      tricks = ((winner & 1) === 0 ? 1 : 0) + search.nsTricks(winner, 0, left - 1);
    } else {
      tricks = search.nsTricks(leader, played + 1, left);
    }
    search.hands[moverIndex * 4 + suit] ^= bit;
    return { card, tricks: northSouth ? tricks : left - tricks };
  });
}

export function bestTricks(state: PlayState): number {
  return Math.max(...solve(state).map((result) => result.tricks));
}
```
