# Installeerbaar, offline en online — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** De app op het beginscherm van een tablet kunnen zetten, hem laten werken zonder internet, en hem online zetten zodat hij met één link te openen is.

**Architecture:** Bij het bouwen schrijft een kleine Vite-plugin een service worker (`sw.js`) met de lijst van alle gebouwde bestanden. Bij het eerste bezoek slaat de browser die bestanden op; daarna komen ze uit die opslag, ook zonder verbinding. Een nieuwe versie van de app krijgt een nieuwe opslag en vervangt de oude zodra de app is afgesloten en opnieuw geopend. Een webmanifest en pictogrammen maken de app installeerbaar. Een GitHub Actions-workflow test, bouwt en publiceert de app op GitHub Pages bij elke push naar `master`.

**Tech Stack:** Vite, een eigen plugin in `vite.config.ts` (geen extra afhankelijkheden), GitHub Actions, GitHub Pages.

Spec: `docs/superpowers/specs/2026-10-03-bridge-app-design.md`, stap 8 van de bouwvolgorde. Vereist dat het plan `2026-10-03-app.md` is uitgevoerd. Dit plan raakt `index.html`, `vite.config.ts` en `src/app/main.tsx`; het kan voor of na het leerpad worden uitgevoerd.

## Global Constraints

- Werkmap voor alle commando's: de map `bridge-app` (de git-root).
- Geen nieuwe npm-afhankelijkheden.
- De service worker wordt alleen in de gebouwde app geregistreerd, niet tijdens `npm run dev`.
- Alle paden in `index.html`, het manifest en de service worker zijn relatief (`./`), zodat de app in een submap van een host werkt (`https://<naam>.github.io/<repository>/`).
- De app verstuurt geen gegevens: voortgang en instellingen blijven op het apparaat.
- Identifiers en commentaar zijn Engels; de naam van de app en teksten voor de gebruiker zijn Nederlands.
- Tests importeren `describe`, `it`, `expect` expliciet uit `vitest`.
- Commitbericht: een onderwerpregel, een lege regel, en daarna letterlijk de regel `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Task 1: De service worker

**Files:**
- Create: `src/pwa/serviceWorker.ts`
- Modify: `vite.config.ts` (volledig vervangen)
- Test: `src/pwa/serviceWorker.test.ts`

**Interfaces:**
- Consumes: niets
- Produces:
  - `serviceWorkerSource(version: string, files: readonly string[]): string` — JavaScript voor `sw.js`. De opslag heet `bridge-<version>`; de lijst bevat `./` en alle `files`.
  - `versionOf(files: readonly string[]): string` — een korte code die verandert zodra een bestandsnaam verandert. Vite zet een hash van de inhoud in elke bestandsnaam, dus een gewijzigde app geeft een nieuwe versie.

Gedrag van de service worker:

- **install:** alle bestanden vers ophalen (langs de eigen cache van de browser) en opslaan. De nieuwe service worker wacht daarna tot de app is afgesloten; een geopende app houdt de bestanden waarmee hij begon.
- **activate:** oudere opslag van deze app verwijderen.
- **fetch:** een GET-verzoek uit de opslag beantwoorden als het er staat, anders via het netwerk.

- [ ] **Step 3: Schrijf de implementatie**

`src/pwa/serviceWorker.ts`:

```ts
// Builds the source of the service worker that keeps the app working without a connection.
// It stores every file of the build on the first visit and serves them from that store afterwards.
// A new build has a new version. Its service worker waits until the app has been closed, so a page
// that is open keeps the files it started with; the old store is removed when the new one takes over.

export function serviceWorkerSource(version: string, files: readonly string[]): string {
  return `const CACHE = ${JSON.stringify(`bridge-${version}`)};
const FILES = ${JSON.stringify(['./', ...files], null, 2)};

self.addEventListener('install', (event) => {
  // 'reload' skips the browser's own cache, so an old copy of a file never ends up in the store
  event.waitUntil(
    caches
      .open(CACHE)
      .then((cache) => cache.addAll(FILES.map((file) => new Request(file, { cache: 'reload' })))),
  );
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) => Promise.all(keys.filter((key) => key !== CACHE).map((key) => caches.delete(key)))),
  );
});

self.addEventListener('fetch', (event) => {
  if (event.request.method !== 'GET') return;
  event.respondWith(
    caches.match(event.request, { ignoreSearch: true }).then((stored) => stored ?? fetch(event.request)),
  );
});
`;
}

// A short stable fingerprint of the file list, so that every build gets its own store
export function versionOf(files: readonly string[]): string {
  let hash = 5381;
  for (const char of [...files].sort().join('|')) {
    hash = ((hash * 33) ^ char.charCodeAt(0)) >>> 0;
  }
  return hash.toString(36);
}
```

Vervang `vite.config.ts` volledig:

`vite.config.ts`:

```ts
import react from '@vitejs/plugin-react';
import { type Plugin, defineConfig } from 'vite';
import { serviceWorkerSource, versionOf } from './src/pwa/serviceWorker';

// Writes sw.js next to the built files, listing all of them for offline use
function offlineSupport(): Plugin {
  return {
    name: 'offline-support',
    apply: 'build',
    generateBundle(_options, bundle) {
      const files = [
        ...Object.keys(bundle),
        'index.html',
        'manifest.webmanifest',
        'icon-180.png',
        'icon-192.png',
        'icon-512.png',
      ];
      this.emitFile({
        type: 'asset',
        fileName: 'sw.js',
        // The build time makes every build a new version, also when only index.html changed
        source: serviceWorkerSource(`${versionOf(files)}-${Date.now().toString(36)}`, files),
      });
    },
  };
}

export default defineConfig({
  plugins: [react(), offlineSupport()],
  // Relative paths, so the built app works from any folder on a static host
  base: './',
});
```

`scripts/make-icons.mjs`:

```
// Draws the app icon (a white playing card with a spade on green felt) and writes it as PNG files.
// Run with: node scripts/make-icons.mjs
import { mkdirSync, writeFileSync } from 'node:fs';
import { deflateSync } from 'node:zlib';

const FELT = [15, 74, 43];
const PAPER = [255, 253, 247];
const INK = [22, 32, 42];

// Colour of the pixel at (x, y), both between 0 and 1
function colourAt(x, y) {
  const inCard = x > 0.24 && x < 0.76 && y > 0.14 && y < 0.86;
  if (!inCard) return FELT;
  // A spade: two circles, a triangle on top of them and a small stem
  const circle = (cx, cy, r) => (x - cx) ** 2 + (y - cy) ** 2 < r * r;
  const top = y > 0.3 && y < 0.56 && Math.abs(x - 0.5) < (y - 0.3) * 0.62;
  const stem = y > 0.56 && y < 0.7 && Math.abs(x - 0.5) < 0.02 + (y - 0.56) * 0.35;
  const spade = top || circle(0.42, 0.55, 0.085) || circle(0.58, 0.55, 0.085) || stem;
  return spade ? INK : PAPER;
}

const CRC_TABLE = Array.from({ length: 256 }, (_, n) => {
  let c = n;
  for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
  return c >>> 0;
});

function crc32(buffer) {
  let c = 0xffffffff;
  for (const byte of buffer) c = CRC_TABLE[(c ^ byte) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}

function chunk(type, data) {
  const length = Buffer.alloc(4);
  length.writeUInt32BE(data.length);
  const body = Buffer.concat([Buffer.from(type, 'ascii'), data]);
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(body));
  return Buffer.concat([length, body, crc]);
}

function png(size) {
  const rows = Buffer.alloc(size * (size * 3 + 1));
  for (let y = 0; y < size; y++) {
    const start = y * (size * 3 + 1);
    rows[start] = 0; // no filter
    for (let x = 0; x < size; x++) {
      const [r, g, b] = colourAt((x + 0.5) / size, (y + 0.5) / size);
      rows.set([r, g, b], start + 1 + x * 3);
    }
  }
  const header = Buffer.alloc(13);
  header.writeUInt32BE(size, 0);
  header.writeUInt32BE(size, 4);
  header.set([8, 2, 0, 0, 0], 8); // 8 bits per channel, RGB
  return Buffer.concat([
    Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]),
    chunk('IHDR', header),
    chunk('IDAT', deflateSync(rows)),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}

mkdirSync('public', { recursive: true });
for (const size of [180, 192, 512]) {
  writeFileSync(`public/icon-${size}.png`, png(size));
  console.log(`public/icon-${size}.png`);
}
```

### Task 3: Online zetten met GitHub Pages

**Files:**
- Create: `.github/workflows/deploy.yml`

**Interfaces:**
- Consumes: `npm ci`, `npm test`, `npm run build`
- Produces: bij elke push naar `master` een gepubliceerde versie van `dist`

- [ ] **Step 1: Maak de workflow**

`.github/workflows/deploy.yml`:

```
name: Deploy to GitHub Pages

on:
  push:
    branches: [master]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 24
          cache: npm
      - run: npm ci
      - run: npm test
      - run: npm run build
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist
      - id: deployment
        uses: actions/deploy-pages@v4
```
