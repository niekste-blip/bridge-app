# Coach: hints, uitleg en nabespreking — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** De coach toevoegen aan de speeltafel: een hintknop bij bieden en afspelen, uitleg bij elk bod in het biedverloop, en na elk spel een nabespreking met hooguit drie leermomenten.

**Architecture:** De module `coach` bevat de inhoud zonder schermcode. Een biedhint is het bod dat de regeltabel voorschrijft. Een speelhint komt uit dezelfde simulatie als de bots gebruiken, of uit de vuistregels zolang er te veel kaarten in de hand zitten. De nabespreking speelt het spel na en beoordeelt elke keuze van de gebruiker op dezelfde manier. Het rekenwerk draait in de bestaande Web Worker.

**Tech Stack:** TypeScript (strict), React 19, Vitest. Bouwt op `src/core`, `src/bidding`, `src/bots`, `src/game` en `src/app`.

Spec: `docs/superpowers/specs/2026-10-03-bridge-app-design.md`, stap 6 van de bouwvolgorde. Vereist dat het plan `2026-10-03-app.md` is uitgevoerd.

## Wat de coach zegt

| Onderdeel | Wanneer | Inhoud |
|---|---|---|
| Biedhint | De gebruiker is aan de beurt om te bieden en tikt op "Hint" | "Advies: " plus de uitleg van de regel, bijvoorbeeld `Advies: 1♥: vanaf 12 punten en minstens 5 harten.` |
| Speelhint met simulatie | Aan de beurt om te spelen, 8 of minder kaarten in de hand | `Advies: speel ♠A. Deze kaart levert in de rest van het spel gemiddeld de meeste slagen op: 1,8. De beste andere kaart haalt 1,2.` |
| Speelhint op vuistregels | Meer dan 8 kaarten in de hand | De vuistregel in woorden, bijvoorbeeld "Tweede hand laag: bewaar uw hoge kaarten." |
| Uitleg bij een bod | Tikken op een bod in het biedverloop | Voor een bot de uitleg die hij erbij gaf; voor een bod van de gebruiker wat de regels eronder verstaan, of "Voor dit bod is geen afspraak." |
| Nabespreking | Na elk spel, in het uitslagvenster | Hooguit drie leermomenten, de belangrijkste eerst |

Een leermoment in de nabespreking is:

- een bod van de gebruiker dat afwijkt van wat een regel voorschrijft (het vangnet telt niet als regel);
- een kaart van de gebruiker die volgens de simulatie gemiddeld minstens één slag kost. Dit wordt alleen beoordeeld met 8 of minder kaarten in de hand.

Biedmomenten komen voor speelmomenten; speelmomenten staan op volgorde van het aantal verloren slagen. Heeft de bot voor de gebruiker geboden ("Zelf bieden" uit), dan worden die biedingen niet beoordeeld.

De nabespreking beoordeelt het afspel dus pas vanaf de zesde slag. Fouten in de eerste vijf slagen blijven onbesproken; dat volgt uit de snelheid van de rekenmodule.

Biedadvies en de beoordeling van het bieden gebruiken alleen regels uit lessen die de gebruiker heeft afgerond, met les 4 als ondergrens. De bots zelf kennen altijd minstens les 7.

```ts
import { type Card, rankLabel, sameCard, seededRng } from '../core';
import { type Choice, STRAIN_SYMBOL, chooseCall, meaningsOf } from '../bidding';
import {
  BASE_LESSON,
  type HeuristicRule,
  type PlayerView,
  SIMULATION_MAX_CARDS,
  evaluateCards,
  handToPlay,
  heuristicChoice,
  legalCardsFor,
  limitsFor,
  viewOfPlay,
} from '../bots';
import { type Game, type Settings, USER, turnOf } from '../game';

export interface CardHint {
  readonly card: Card;
  // Why this card, in Dutch, without naming the card itself
  readonly text: string;
}

export interface CardHintOptions {
  readonly seed: number;
  readonly maxLesson: number;
  // 0 gives the rule of thumb without simulation
  readonly samples?: number;
  readonly budgetMs?: number;
  readonly now?: () => number;
}

export const NO_AGREEMENT = 'Voor dit bod is geen afspraak.';
const HINT_SAMPLES = 40;
const EPSILON = 1e-9;

const RULE_TEXT: Readonly<Record<HeuristicRule, string>> = {
  'draw-trumps': 'Trek troef: speel uw hoogste troef, zodat de tegenstanders niet kunnen aftroeven.',
  'cash-winner': 'Deze kaart kan niemand slaan: haal de slag binnen.',
  'long-suit': 'Kom uit in uw langste kleur om daar slagen te maken.',
  'second-hand-low': 'Tweede hand laag: bewaar uw hoge kaarten.',
  'cover-honour': 'Honneur op honneur: sla de hoge kaart van de tegenstander.',
  'third-hand-high': 'Derde hand hoog: probeer de slag te winnen.',
  'win-cheaply': 'U speelt als laatste: win de slag met de laagste kaart die genoeg is.',
  'play-low': 'Deze slag kunt u niet winnen, of partner wint hem al: speel laag.',
  ruff: 'U kunt niet bekennen: troef de slag met een lage troef.',
  discard: 'U kunt niet bekennen: gooi een lage kaart weg.',
};

export function cardName(card: Card): string {
  return `${STRAIN_SYMBOL[card.suit]}${rankLabel(card.rank)}`;
}

// One decimal with a comma, as in Dutch
export function tricksText(value: number): string {
  return value.toFixed(1).replace('.', ',');
}

// The bots never know less than lesson 7, and neither does the advice
export function lessonFor(settings: Settings): number {
  return Math.max(BASE_LESSON, settings.progressLesson);
}

// Bidding advice for the user never uses a rule from a lesson she has not finished,
// with lesson 4 (opening) as the least
const FIRST_BIDDING_LESSON = 4;

export function adviceLesson(settings: Settings): number {
  return Math.max(FIRST_BIDDING_LESSON, settings.progressLesson);
}

// The call the rules prescribe for the user now; null when it is not the user's turn to call
export function callHint(game: Game, settings: Settings): Choice | null {
  const turn = turnOf(game);
  if (!turn || turn.kind !== 'call' || !turn.byUser) return null;
  return chooseCall(game.deal[USER], game.auction, { maxLesson: adviceLesson(settings) });
}

export function cardHintFor(view: PlayerView, options: CardHintOptions): CardHint {
  const legal = legalCardsFor(view);
  if (legal.length === 1) {
    return { card: legal[0], text: 'Dit is de enige kaart die u mag spelen.' };
  }
  const thumb = heuristicChoice(view);
  const samples = options.samples ?? HINT_SAMPLES;
  if (samples === 0 || handToPlay(view).length > SIMULATION_MAX_CARDS) {
    return { card: thumb.card, text: RULE_TEXT[thumb.rule] };
  }

  const evaluations = evaluateCards(view, {
    samples,
    rng: seededRng(options.seed),
    limits: limitsFor(view, options.maxLesson),
    budgetMs: options.budgetMs,
    now: options.now,
  });
  const best = Math.max(...evaluations.map((evaluation) => evaluation.average));
  const bestCards = evaluations.filter((e) => best - e.average < EPSILON).map((e) => e.card);
  if (bestCards.length === evaluations.length) {
    return {
      card: thumb.card,
      text: `Alle kaarten leveren hier evenveel slagen op. ${RULE_TEXT[thumb.rule]}`,
    };
  }
  const card =
    bestCards.find((candidate) => sameCard(candidate, thumb.card)) ??
    bestCards.reduce((lowest, candidate) => (candidate.rank < lowest.rank ? candidate : lowest));
  const second = Math.max(
    ...evaluations.filter((e) => best - e.average >= EPSILON).map((e) => e.average),
  );
  return {
    card,
    text: `Deze kaart levert in de rest van het spel gemiddeld de meeste slagen op: ${tricksText(best)}. De beste andere kaart haalt ${tricksText(second)}.`,
  };
}

// The card to advise the user now; null when it is not the user's turn to play
export function cardHint(
  game: Game,
  settings: Settings,
  options: Partial<CardHintOptions> = {},
): CardHint | null {
  const turn = turnOf(game);
  if (!turn || turn.kind !== 'card' || !turn.byUser || !game.play) return null;
  const cardsPlayed = game.play.completed.length * 4 + game.play.current.cards.length;
  return cardHintFor(viewOfPlay(game.play, game.auction), {
    seed: game.seed * 100 + cardsPlayed + 50,
    maxLesson: lessonFor(settings),
    ...options,
  });
}

// What the call at this position means: the explanation the bot gave, or what the rules say
export function callMeaning(game: Game, index: number, settings: Settings): string {
  const note = game.notes[index];
  if (note) return note;
  const meanings = meaningsOf(game.auction, index, { maxLesson: lessonFor(settings) });
  return meanings.length > 0 ? meanings.join(' Of: ') : NO_AGREEMENT;
}
```

```ts
import { type Deal, auctionFrom, parseCard, playCard, startPlay } from '../core';
import { type Game } from '../game';

// Test helper: a finished four-card board in which South, the user, declares 1NT.
// West leads a club to South's ace. South then holds the two top spades and a small diamond;
// `secondTrick` chooses what South does with them.
export function fourCardBoard(secondTrick: 'cash' | 'blunder'): Game {
  const parse = (text: string) => text.split(' ').map(parseCard);
  const deal: Deal = {
    N: parse('C2 S3 S4 H2'),
    E: parse('C4 SJ DK H3'),
    S: parse('CA SA SK D2'),
    W: parse('C5 SQ DA D3'),
  };
  const auction = auctionFrom('N', 'P P 1NT P P P');
  const contract = { level: 1, strain: 'NT', doubling: 'none', declarer: 'S' } as const;
  const cards =
    secondTrick === 'blunder'
      ? 'C5 C2 C4 CA D2 DA S3 DK D3 S4 H3 SK SQ H2 SJ SA'
      : 'C5 C2 C4 CA SA SQ S3 SJ SK D3 S4 H3 D2 DA H2 DK';
  const play = cards.split(' ').reduce((state, id) => playCard(state, parseCard(id)), startPlay(deal, contract));
  return {
    board: 1,
    seed: 1,
    dealer: 'N',
    vulnerability: 'none',
    deal,
    auction,
    notes: ['Pas: test.', 'Pas: test.', null, 'Pas: test.', 'Pas: test.', 'Pas: test.'],
    contract,
    play,
    undo: null,
  };
}
```

```ts
import {
  callerAt,
  dummyOf,
  legalCards,
  playCard,
  sameCall,
  sameCard,
  seatToPlay,
  seededRng,
  startPlay,
} from '../core';
import { callLabel, chooseCall } from '../bidding';
import { SIMULATION_MAX_CARDS, evaluateCards, limitsFor, viewOfPlay } from '../bots';
import { type Game, type Settings, USER } from '../game';
import { adviceLesson, cardName, lessonFor, tricksText } from './hint';

export interface Moment {
  readonly kind: 'call' | 'card';
  readonly text: string;
  // Used to put the most important moment first
  readonly weight: number;
}

export interface ReviewOptions {
  // 0 skips the review of the card play
  readonly samples?: number;
  readonly budgetMs?: number;
  readonly now?: () => number;
}

export const MAX_MOMENTS = 3;
// A card is only mentioned when it costs at least this many tricks on average
const MIN_LOSS = 1;
// Bidding moments come before card moments
const CALL_WEIGHT = 100;
const REVIEW_SAMPLES = 30;

function callMoments(game: Game, settings: Settings): Moment[] {
  const moments: Moment[] = [];
  game.auction.calls.forEach((call, index) => {
    // A call with a note was made by a bot, also when the bots bid the hand of the user
    if (callerAt(game.auction, index) !== USER || game.notes[index] !== null) return;
    const before = { dealer: game.auction.dealer, calls: game.auction.calls.slice(0, index) };
    const advice = chooseCall(game.deal[USER], before, { maxLesson: adviceLesson(settings) });
    if (advice.source !== 'rule' || sameCall(advice.call, call)) return;
    const did = call.type === 'pass' ? 'u paste' : `u bood ${callLabel(call)}`;
    moments.push({
      kind: 'call',
      text: `Bieden: ${did}. Volgens de afspraken is het ${advice.explanation}`,
      weight: CALL_WEIGHT - index,
    });
  });
  return moments;
}

function cardMoments(game: Game, settings: Settings, options: ReviewOptions): Moment[] {
  const samples = options.samples ?? REVIEW_SAMPLES;
  if (samples === 0 || !game.play || !game.contract) return [];
  const moments: Moment[] = [];
  let state = startPlay(game.deal, game.contract);
  const cards = [...game.play.completed, game.play.current].flatMap((trick) => trick.cards);

  cards.forEach((card, cardsPlayed) => {
    const seat = seatToPlay(state);
    const dummy = dummyOf(state);
    const actor = seat === dummy ? state.declarer : seat;
    const judged =
      actor === USER &&
      legalCards(state).length > 1 &&
      state.hands[seat].length <= SIMULATION_MAX_CARDS;
    if (judged) {
      const view = viewOfPlay(state, game.auction);
      const evaluations = evaluateCards(view, {
        samples,
        rng: seededRng(game.seed * 100 + cardsPlayed + 50),
        limits: limitsFor(view, lessonFor(settings)),
        budgetMs: options.budgetMs,
        now: options.now,
      });
      const best = evaluations.reduce((a, b) => (b.average > a.average ? b : a));
      const played = evaluations.find((evaluation) => sameCard(evaluation.card, card));
      const loss = played ? best.average - played.average : 0;
      if (loss >= MIN_LOSS) {
        const from = seat === dummy ? ' uit de dummy' : '';
        moments.push({
          kind: 'card',
          text: `Slag ${state.completed.length + 1}: u speelde ${cardName(card)}${from}. Met ${cardName(best.card)} haalt u gemiddeld ${tricksText(loss)} slag meer.`,
          weight: loss,
        });
      }
    }
    state = playCard(state, card);
  });
  return moments;
}

// At most three things to learn from this board, the most important first
export function reviewOf(game: Game, settings: Settings, options: ReviewOptions = {}): Moment[] {
  return [...callMoments(game, settings), ...cardMoments(game, settings, options)]
    .sort((a, b) => b.weight - a.weight)
    .slice(0, MAX_MOMENTS);
}
```

```ts
// Work that may take a while and therefore runs in the worker
export type Task =
  | { readonly kind: 'bot'; readonly request: BotRequest }
  | { readonly kind: 'hint'; readonly game: Game; readonly settings: Settings }
  | { readonly kind: 'review'; readonly game: Game; readonly settings: Settings };

// Time for the simulation behind one judged card in the review
const REVIEW_BUDGET_MS = 300;

export function runTask(task: Task): TaskResult {
  switch (task.kind) {
    case 'bot':
      return answer(task.request);
    case 'hint':
      return cardHint(task.game, task.settings, { budgetMs: THINKING_BUDGET_MS });
    case 'review':
      return reviewOf(task.game, task.settings, { budgetMs: REVIEW_BUDGET_MS });
  }
}

// The same work without simulation, for when the worker does not answer in time
export function quickResult(task: Task): TaskResult {
  switch (task.kind) {
    case 'bot':
      return quickAnswer(task.request);
    case 'hint':
      return cardHint(task.game, task.settings, { samples: 0 });
    case 'review':
      return reviewOf(task.game, task.settings, { samples: 0 });
  }
}
```

```ts
import { type CardHint, type Moment } from '../coach';
import { type BotAnswer, type BotRequest, type Game, type Settings } from '../game';
import { type Task, type TaskResult, quickResult } from './tasks';

// Work that has not come back after this long is redone without simulation
const TIMEOUT_MS = 5000;
// The review judges many cards and gets more time
const REVIEW_TIMEOUT_MS = 20000;

interface Waiting {
  readonly task: Task;
  readonly resolve: (result: TaskResult) => void;
  readonly timer: ReturnType<typeof setTimeout>;
}

let worker: Worker | null = null;
let nextId = 1;
const waiting = new Map<number, Waiting>();

// Stops the worker and answers everything that was waiting without simulation.
// A worker that is too slow, or that could not be loaded, would otherwise hold up every later task.
function abandonWorker(): void {
  worker?.terminate();
  worker = null;
  for (const [id, entry] of [...waiting]) {
    waiting.delete(id);
    clearTimeout(entry.timer);
    entry.resolve(quickResult(entry.task));
  }
}

function taskWorker(): Worker {
  if (!worker) {
    worker = new Worker(new URL('./botWorker.ts', import.meta.url), { type: 'module' });
    worker.onmessage = (event: MessageEvent<{ id: number; result: TaskResult }>) => {
      const entry = waiting.get(event.data.id);
      if (!entry) return;
      waiting.delete(event.data.id);
      clearTimeout(entry.timer);
      entry.resolve(event.data.result);
    };
    worker.onerror = abandonWorker;
  }
  return worker;
}

function run(task: Task, timeoutMs: number): Promise<TaskResult> {
  return new Promise((resolve) => {
    const id = nextId++;
    waiting.set(id, { task, resolve, timer: setTimeout(abandonWorker, timeoutMs) });
    try {
      taskWorker().postMessage({ id, task });
    } catch {
      abandonWorker();
    }
  });
}

export function askBot(request: BotRequest): Promise<BotAnswer> {
  return run({ kind: 'bot', request }, TIMEOUT_MS) as Promise<BotAnswer>;
}

export function askHint(game: Game, settings: Settings): Promise<CardHint | null> {
  return run({ kind: 'hint', game, settings }, TIMEOUT_MS) as Promise<CardHint | null>;
}

export function askReview(game: Game, settings: Settings): Promise<Moment[]> {
  return run({ kind: 'review', game, settings }, REVIEW_TIMEOUT_MS) as Promise<Moment[]>;
}
```

```tsx
              {seat === USER && settings.showPoints && ` · ${highCardPoints(game.deal[USER])} punten`}
            </h3>
            {hand(seat)}
          </section>
        ))}
        <section className="centre">
          {over ? (
            <ResultPanel
              game={game}
              review={props.review}
              onNext={props.onNext}
              onReplay={props.onReplay}
            />

            <TrickArea play={game.play} toPlay={turn?.seat ?? null} />

            <AuctionGrid
              auction={game.auction}
              vulnerability={game.vulnerability}
              meaning={props.meaning}
            />
          )}
        </section>
      </main>

      <footer className="action-bar">
        <p className="status" aria-live="polite">
          {status()}
        </p>
        {props.hint && turn?.byUser && <p className="hint">{props.hint}</p>}
        {turn?.kind === 'call' && turn.byUser && (
          <BiddingBox auction={game.auction} onCall={props.onCall} />
        )}
        {userPlays && (
          <button type="button" className="primary confirm" disabled={!chosen} onClick={playChosen}>
            {chosen ? `Speel ${cardLabel(chosen)}` : 'Kies een kaart'}
          </button>

        {turn?.byUser && (

            Hint
          </button>
        )}
        {canUndo(game) && (
          <button type="button" onClick={props.onUndo}>
            Neem terug
          </button>
        )}
      </footer>
    </div>
  );
}
```

`src/app/App.tsx`:

```tsx
import { useEffect, useReducer, useState } from 'react';
import { type Moment, callHint, callMeaning, cardName } from '../coach';
import { FRESH, type Game, botRequestFor, load, phaseOf, save, turnOf } from '../game';
import { askBot, askHint, askReview } from './botClient';
import './coach.css';
import { HomeScreen } from './components/HomeScreen';
import { SettingsScreen } from './components/SettingsScreen';
import { TableScreen } from './components/TableScreen';
import { initialState, reduce } from './state';

// Pause before a bot acts, so the user can follow the play; longer after a finished trick
const BOT_DELAY_MS = 700;
const TRICK_DELAY_MS = 1600;

// Storage can be blocked or full; the app then simply runs without saving
function start() {
  try {
    const { saved, recovered } = load(window.localStorage);
    return initialState(saved, recovered);
  } catch {
    return initialState(FRESH, false);
  }
}

export function App() {
  const [state, dispatch] = useReducer(reduce, undefined, start);
  const { saved, screen } = state;
  const { game, settings } = saved;

  useEffect(() => {
    try {
      save(window.localStorage, saved);
    } catch {
      // Nothing to do: the game goes on, it just is not kept
    }
  }, [saved]);

  useEffect(() => {
    if (!game || screen !== 'table') return;
    const request = botRequestFor(game, settings);
    if (!request) return;
    let cancelled = false;
    const trickJustFinished =
      game.play !== null && game.play.current.cards.length === 0 && game.play.completed.length > 0;
    const timer = setTimeout(
      () => {
        void askBot(request).then((answer) => {
          if (!cancelled) dispatch({ type: 'bot', answer, forGame: game });
        });
      },
      trickJustFinished ? TRICK_DELAY_MS : BOT_DELAY_MS,
    );
    return () => {
      cancelled = true;
      clearTimeout(timer);
    };
  }, [game, settings, screen]);

  // Advice and review belong to one position; they are dropped as soon as the game moves on
  const [hint, setHint] = useState<{ game: Game; text: string } | null>(null);
  const [review, setReview] = useState<{ game: Game; moments: Moment[] } | null>(null);

  const showHint = () => {
    if (!game) return;
    const turn = turnOf(game);
    if (turn?.kind === 'call') {
      const advice = callHint(game, settings);
      if (advice) setHint({ game, text: `Advies: ${advice.explanation}` });
      return;
    }
    setHint({ game, text: 'Even denken…' });
    void askHint(game, settings).then((advice) => {
      if (advice) {
        setHint({ game, text: `Advies: speel ${cardName(advice.card)}. ${advice.text}` });
      }
    });
  };

  useEffect(() => {
    if (!game || screen !== 'table') return;
    const phase = phaseOf(game);
    if (phase !== 'finished' && phase !== 'passedOut') return;
    let cancelled = false;
    void askReview(game, settings).then((moments) => {
      if (!cancelled) setReview({ game, moments });
    });
    return () => {
      cancelled = true;
    };
  }, [game, settings, screen]);

  const newBoard = () => dispatch({ type: 'newBoard', seed: Math.floor(Math.random() * 1_000_000) + 1 });

  return (
    <div className={`app text-${settings.textSize}`}>
      {screen === 'table' && game ? (
        <TableScreen
          game={game}
          settings={settings}
          hint={hint?.game === game ? hint.text : null}
          review={review?.game === game ? review.moments : null}
          meaning={(index) => callMeaning(game, index, settings)}
          onHint={showHint}
          onCall={(call) => dispatch({ type: 'call', call })}
          onCard={(card) => dispatch({ type: 'card', card })}
          onUndo={() => dispatch({ type: 'undo' })}
          onNext={newBoard}
          onReplay={() => dispatch({ type: 'replay' })}
          onHome={() => dispatch({ type: 'go', screen: 'home' })}
        />
      ) : screen === 'settings' ? (
        <SettingsScreen
          settings={settings}
          onChange={(next) => dispatch({ type: 'settings', settings: next })}
          onReset={() => dispatch({ type: 'reset' })}
          onBack={() => dispatch({ type: 'go', screen: 'home' })}
        />
      ) : (
        <HomeScreen
          game={game}
          notice={state.notice}
          onContinue={() => dispatch({ type: 'go', screen: 'table' })}
          onNew={() => {
            const running = game !== null && turnOf(game) !== null;
            if (!running || window.confirm('Het lopende spel stoppen en een nieuw spel beginnen?')) {
              newBoard();
            }
          }}
          onSettings={() => dispatch({ type: 'go', screen: 'settings' })}
          onDismissNotice={() => dispatch({ type: 'dismissNotice' })}
        />
      )}
    </div>
  );
}
```
